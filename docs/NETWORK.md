# Сеть и firewall

## Требования до установки

- Исходящий HTTPS к `installer.cloudpanel.io` и зеркалам пакетов Debian/MariaDB/MySQL.
- Рабочий DNS.
- Маршрут по умолчанию.
- Публичный IPv4 (или корректный NAT + проброс портов). IPv6 опционален, проверяется отдельно.

## Порты

См. также `config/firewall-requirements.md`.

| Порт | Назначение | Источник |
|------|------------|----------|
| 22/tcp | SSH | Только админ / VPN |
| 80/tcp | HTTP, ACME | Публично для сайтов |
| 443/tcp | HTTPS | Публично |
| 443/udp | HTTP/3 | По необходимости |
| 8443/tcp | CloudPanel UI | Только IP администратора |

Официальный установщик **откажется** работать, если заняты порты **80, 443 или 3306**.

## Слои фильтрации

1. Security Group / firewall панели VPS (предпочтительно).
2. UFW внутри CloudPanel (после установки).

Не включайте одновременно несколько конфликтующих firewall-менеджеров без плана.

## Диагностика доступности UI

```bash
# Локально на сервере
curl -vk https://127.0.0.1:8443/

# Слушает ли порт
ss -tlnp | grep 8443

# Локальный firewall
sudo ufw status verbose

# Публичный IP
curl -4 https://api.ipify.org; echo
```

Если локально OK, а извне нет — проблема во внешнем firewall/NAT, а не в CloudPanel.
