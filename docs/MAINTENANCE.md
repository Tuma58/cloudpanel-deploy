# Эксплуатация и обслуживание

## После ввода в эксплуатацию

1. Ограничьте SSH и 8443 по IP.
2. Включите 2FA для пользователей CloudPanel (официальная рекомендация).
3. При отсутствии статического IP — Basic Auth перед панелью.
4. Настройте Remote Backups.
5. Следите за обновлениями CloudPanel и ОС.

## Обновления системы

```bash
sudo apt update
apt list --upgradable
# Плановое окно обслуживания:
sudo apt upgrade
# При /var/run/reboot-required — reboot через консоль провайдера при необходимости
```

Не обновляйте «вслепую» накануне релизов без снимка/бэкапа.

Через этот проект можно включить `APPLY_SECURITY_UPDATES=YES` в `10-prepare-system.sh` **до** установки панели. После установки обновления выполняйте штатными средствами ОС/CloudPanel.

## Обновление CloudPanel

Следуйте официальной документации обновлений CloudPanel. Не подменяйте пакеты панели сторонними репозиториями.

## Мониторинг минимальный набор

- Доступность HTTPS сайта и порта 8443 (с ограничением источника).
- Свободное место на диске.
- Успешность бэкапов.
- Срок TLS-сертификатов.
- Нагрузка RAM/CPU на пиках WordPress.

## Журналы этого проекта

Каталог `logs/` — диагностика развёртывания. Не публикуйте их и не коммитьте. Ротация: удаляйте старые файлы после успешного ввода в эксплуатацию, сохранив копию вне сервера при инцидентах.
