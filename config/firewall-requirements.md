# Требования к сетевым портам (CloudPanel)

Источники:

- [Best Practices — Security](https://www.cloudpanel.io/docs/v2/guides/best-practices/security/)
- [Admin Area — Security / Firewall](https://www.cloudpanel.io/docs/v2/admin-area/security/)
- Примеры правил security group в документации облачных провайдеров CloudPanel

## Обязательные порты

| Порт | Протокол | Назначение | Рекомендуемый источник |
|------|----------|------------|------------------------|
| 22 | TCP | SSH | Только IP администратора / VPN |
| 80 | TCP | HTTP, ACME HTTP-01 | Публично (для сайтов и Let's Encrypt) |
| 443 | TCP | HTTPS | Публично |
| 443 | UDP | HTTP/3 (QUIC), если используется | Публично (по необходимости) |
| 8443 | TCP | Веб-интерфейс CloudPanel | Только IP администратора |

## Где настраивать

1. **Firewall / Security Group провайдера VPS** — предпочтительный слой фильтрации (рекомендация CloudPanel).
2. **Встроенный UFW CloudPanel** — дополнительный слой; не дублируйте конфликтующие менеджеры (firewalld + ufw одновременно).

## Чего не делать

- Не открывать 8443 всему интернету без крайней необходимости.
- Не закрывать SSH, пока нет альтернативного доступа через консоль провайдера.
- Не открывать 3306/TCP во внешний мир.
- Не отключать firewall «чтобы установить быстрее».

## После установки

1. Создайте администратора CloudPanel как можно быстрее.
2. Ограничьте 8443 вашим IP.
3. Если статический IP недоступен — включите Basic Auth перед панелью и/или используйте VPN.
